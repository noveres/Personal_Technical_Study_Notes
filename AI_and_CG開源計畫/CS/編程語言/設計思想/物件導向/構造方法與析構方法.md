### 構造函數
 
 >
 >在對象被創建時調用，常用來**初始化**對象內部的成員、進行必要的資源分配
 >

  具有以下幾個特性：

- **產生類 (Defining/Creating a Class)** 的 **實例** 中被自動調用
- 函數名與類名相同
- 沒有返回值
- 可以進行重載

>
>構造函數：本質是生成對象處理階段的處理邏輯，這個階段生成的就是這個類的對象，所以不需要返回某個結果
>

記憶體分配：
- 當執行 實例化 或 new 一個引用出來時，作業系統或執行期環境（Runtime）已經根據「類」這個模板的大小，**分配記憶體空間給這個實例了**
- 空間切好後，系統會立刻把這塊剛出生的記憶體交給 **構造函數** 進行內容的操作
  如：初始化就是進去這塊記憶體裡面，把裡面的屬性（數據）填上初始值。

>
>構造方法編譯器會自動幫我們隱式生成一個「無參數、內容為空」的構造方法
>

假設：

```c++
class Human {
public:
    std::string name;
    int age;
    // 這裡空空如也，什麼構造方法都沒寫
};
```

編譯器在編譯時，會默默地補上

```c++
Human() {
    // 內容是空的，什麼都沒做
}
```

依然可以順利調用`Human()`來生成對象，而程式不會報錯的原因。因為系統在「生成對象處理階段」，依然有這個自動生成的構造方法可以呼叫。
