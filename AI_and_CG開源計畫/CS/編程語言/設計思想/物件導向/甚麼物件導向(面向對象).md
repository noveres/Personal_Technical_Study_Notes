物件導向是一種程式設計思想，是將所用到的數據與操作數據的方法，封裝成一個**物件 ( object )**，並圍繞這個 **物件 ( object )** 進行設計的一種思想，它本質上是一種讓項目更健康的一種指導性原則，**而非是一種語法**，所以在 **過程導向(面向過程)** 的語言例如 C 語言中，我們也可以使用物件導向的思想進行開發

物件（Object）：具有兩種性質，稱為屬性（Attributes）及方法（Methods），也對應程式語言的本質，如何 **定義數據狀態** 以及 **操作這個狀態的方式**

### 補充
最經典的做法就是用 `struct` ( 結構體 )把資料包起來，再用**函式指標**模擬「方法」：

``` c
typedef struct Dog {
    char name[20];
    void (*bark)(struct Dog *self);  // 模擬方法
} Dog;

void dog_bark(Dog *self) {
    printf("%s: Woof!\n", self->name);
}

int main(void) {
    Dog d = { "Lucky", dog_bark };
    d.bark(&d);   // 看起來就像 d.bark()
    return 0;
}
```

這裡 `struct` 扮演物件的「狀態」，函式指標扮演「行為」，傳進去的 `self` 就等於其他語言隱藏的 `this`。Linux 核心、GTK 的 GObject 都是用這種手法在 C 裡實作出繼承與多型的
