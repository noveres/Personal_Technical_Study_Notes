
>
>   類( Class ) 就像是用來生產產品的模具，實例 ( Instantiation )就是依照模具產生的產品
>   類是一種描述，而實例是具體佔用內存空間的一種對象，擁有所屬類定義的屬性和方法
>   

```C++
#include <iostream>
#include <string>

// 定義「人類」這個類（模板）
class Human {
public:
    // 屬性的定義 (描述數據結構)
    std::string name;  // 名字
    int age;           // 年齡
    std::string gender;// 性別

    // 一個簡單的功能 (描述行為)
    void Introduce() {
        std::cout << "大家好，我叫 " << name << "，今年 " << age << " 歲，是個 " << gender << " 生。\n";
    }
};

int main() {
    // 實例化：生產一個具體佔用記憶體空間的人
    Human person1;
    
    // 給這個實例賦予具體的屬性值
    person1.name = "陳小明";
    person1.age = 25;
    person1.gender = "男";

    // 呼叫它的功能
    person1.Introduce();

    return 0;
}
```

### 類( Class )
一種生產物件的藍圖，用來描述 **屬性** ( **數據的結構**) 與 **行為** ( **函數、方法** )

1. **屬性（Attributes）：** 
	- 用來敘述物件特性與狀態的資料

2. **方法（Methods）：**
	- 通常是 class 中的 function
	- 例：在「car」物件中，方法可以是 `加速()`、`剎車()`、`開門()`


### 實例 ( Instantiation )
具體佔用內存空間的獨立的程式對向對象

1. 獨立性（Independence）
	- 用同一個類生產出來的多個實例，都分別具有獨立的記憶體位址
	- 修改了實例 A 的屬性，實例 B 絕不會受到影響。
2. 生命週期（Lifecycle)
	- 實例不是永久存在的，會透過 [[構造方法與析構方法]] 經歷 誕生 > 存活 > 消亡
